# 视频分析原生化重构需求澄清

> 状态：Windows 主链路已收敛为 GPU 预处理 sidecar + C++ ONNX Runtime CUDA analyzer + Python 结果汇总 + 前端 overlay。本文档记录当前目标边界和后续迁移依据。

## 当前实现摘要

当前桌面分析链路：

```text
Tauri/Rust
  -> 写入 job JSON
  -> 启动 desktop_worker
  -> stdout NDJSON 接收 progress/result

desktop_worker.py
  -> 可选调用 var-gpu-preprocessor.exe
       -> output/preprocessed.mp4
       -> preprocessingBenchmark
  -> 调用 var-video-analyzer.exe
       -> ONNX Runtime CUDA EP
       -> output/detections.json
       -> detectionBenchmark
  -> Python 事件生成 / 动态指标 / 结果汇总

frontend
  -> 播放 preprocessed.mp4 或原始视频
  -> 读取 detections.json
  -> canvas overlay bbox
```

默认不再生成 `output/result.mp4`。标注视频导出作为后续按需功能单独实现。

## 已删除的旧链路

已从真实链路删除：

- Python PT/ONNX detector fallback。
- `ONNXDetector` / `YOLOTracker` / `detector_factory`。
- Python CPU 预处理器 `preprocessor/video_preprocessor.py`。
- 旧 Web/CPU 视频写入工具 `utils/video_storage.py`。
- HTTP callback 兼容路径。
- `PREPROCESSED_VIDEO_PATH`、`BACKEND_BASE_URL`、`get_callback_url()` 等 Web 端残留配置。
- `requests`、`scipy`、`Pillow`、Python `onnxruntime`、`ultralytics`、`torch` 等正式 worker 运行依赖。

## 缺陷检测

- 模型资产：
  - 源模型：`ai-processor/weights/best.pt`
  - Windows runtime 模型：`ai-processor/weights/best.onnx`
- ONNX 导出命令：`npm run desktop:export-onnx`
- 正式检测后端：`var-video-analyzer.exe`
- runtime provider：`CUDAExecutionProvider`
- 无 GPU / CUDA 初始化失败时：明确失败，不回退 CPU。

ONNX 输入输出：

- input: `[1, 3, 640, 1024]`
- output: `[1, 10, 13440]`

缺陷类别：

- 0 → 熔池未到边 → `POOL_NOT_REACHED`
- 1 → 电极粘连物 → `ADHESION`
- 2 → 锭冠 → `CROWN`
- 3 → 辉光 → `GLOW`
- 4 → 边弧（侧弧） → `SIDE_ARC`
- 5 → 爬弧 → `CREEPING_ARC`

## 事件生成

- 帧号统一采用 0-based frame index。
- 检测证据帧前后各 1 秒生成事件区间。
- 1 秒半径按源视频 FPS 计算。
- 同类别内部重叠或相邻区间合并。
- 不同类别即使时间重叠，也保留为独立事件。
- 不恢复 tracking、`objectId`、`trackingObjects`、`trajectory_json`。

## 预处理

- 正式 Windows 链路只使用 `var-gpu-preprocessor.exe`。
- 启用预处理时输出 `output/preprocessed.mp4`。
- 预处理 benchmark 写入 `performance.preprocessingBenchmark`。
- CPU 预处理不作为正式 fallback。
- 无 GPU、NVDEC/NVENC 不可用、codec 不支持或 sidecar 缺失时明确失败。

## 输出和前端展示

默认产物：

- `output/preprocessed.mp4`：启用预处理时生成。
- `output/detections.json`：分析任务完成时生成。
- `output/result.mp4`：默认不生成。

前端：

- 默认优先播放预处理视频。
- 没有预处理视频时播放原始视频。
- `VideoPlayer.vue` 读取逐帧 detections，用 canvas overlay 绘制 bbox、类别名和 confidence。
- overlay 不拦截视频点击。

## Windows runtime 构建

命令：

```powershell
cd frontend
npm run desktop:windows:runtime
```

顺序：

1. 从 `best.pt` 导出 `best.onnx`。
2. 构建 GPU sidecars。
3. 打包 Python worker。
4. 生成 CUDA runtime zip。

runtime zip 包含：

- `desktop_worker.exe`
- `var-gpu-preprocessor.exe`
- `var-video-analyzer.exe`
- `models/best.onnx`
- sidecar 所需 CUDA/cuDNN/ONNX Runtime/OpenCV/FFmpeg DLL

runtime zip 不包含：

- PyTorch / Ultralytics
- Python ONNX Runtime
- CPU fallback runtime
- 训练依赖
