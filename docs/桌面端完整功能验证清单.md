# 桌面端完整功能验证清单

本文档覆盖当前 Tauri 桌面端功能验证，不覆盖 macOS 签名、notarization、staple、Gatekeeper 等发布动作。

- macOS 发布流程见 [`macOS桌面端发布指南.md`](./macOS桌面端发布指南.md)。
- Windows 双包发布流程见 [`Windows桌面端发布指南.md`](./Windows桌面端发布指南.md)。

## 1. 当前结论

截至 `0.1.6` 当前代码状态，桌面端主链路已调整为：

1. 桌面端导入本地视频并创建任务。
2. Tauri/Rust 写入 SQLite、维护 FIFO 队列并启动 worker。
3. worker 可选调用 `var-gpu-preprocessor.exe` 生成 `output/preprocessed.mp4`。
4. worker 调用 `var-video-analyzer.exe` 使用 `best.onnx` 和 ONNX Runtime CUDA EP 生成逐帧 detections。
5. worker 写入 `output/detections.json`，并通过 stdout NDJSON 提交结果摘要。
6. 前端播放预处理视频；没有预处理视频时播放原始视频，并用 `detections.json` 做 bbox overlay。

默认链路不再生成 `output/result.mp4`，也不再保留 Python PT/ONNX fallback。Windows 导出、构建和运行时均要求 NVIDIA GPU/CUDA 链路可用。

## 3. 必须补测

### A. Windows CUDA 主链路

- [ ] `npm run desktop:windows:runtime`
  - 验收标准：按顺序完成 ONNX 导出、GPU sidecar 构建、worker 打包和 runtime zip 生成。
- [ ] 首次启动导入 runtime zip
  - 验收标准：未导入 runtime 时不能进入主程序；导入正确 zip 后先通过主程序锁定 SHA256 校验，再通过 manifest、逐文件 hash 和所有自检。
- [ ] 导入错误 runtime zip
  - 验收标准：zip 大小或 SHA256 与 `runtime-package-lock.json` 不一致时拒绝导入，并提示选择主程序配套算法包。
- [ ] 启用预处理任务
  - 验收标准：任务 `COMPLETED`，`output/preprocessed.mp4` 和 `output/detections.json` 存在，`output/result.mp4` 默认不存在。
- [ ] 不启用预处理任务
  - 验收标准：任务 `COMPLETED`，播放器默认使用原始视频，overlay 正常显示或为空。
- [ ] 无 GPU / CUDA 不可用机器
  - 验收标准：ONNX 导出、sidecar self-check、GPU 预处理真实视频烟测或 runtime 导入阶段明确失败，不静默回退 CPU。

### B. 前端 Overlay

- [ ] 任务完成后无需等待结果视频即可展示 bbox
  - 验收标准：详情页读取 `get_detection_results(taskId)`，视频上方 bbox 与当前帧同步。
- [ ] 原始视频 / 预处理视频切换
  - 验收标准：启用预处理时默认播放预处理视频；未启用预处理时默认播放原始视频。
- [ ] 播放、暂停、拖动进度、上一帧/下一帧
  - 验收标准：当前帧 bbox 更新正确，overlay 不拦截视频点击。
- [ ] 当前帧无 detection
  - 验收标准：overlay 为空，播放器和详情页正常。

### C. 任务生命周期

- [ ] 删除任务
  - 验收标准：数据库记录删除，任务目录清理，UI 卡片消失。
- [ ] 重新分析
  - 验收标准：旧 `preprocessed.mp4` / `detections.json` 清理或替换，任务重新进入执行并可完成。
- [ ] 多任务排队
  - 验收标准：多个任务按队列顺序执行，无状态串扰。
- [ ] 重启恢复策略
  - 验收标准：等待中 / 执行中重启后状态符合预期，不出现伪“分析中”。
- [ ] 超时路径
  - 验收标准：能稳定进入 `COMPLETED_TIMEOUT`，不是卡死或误判为 `FAILED`。

### D. 报告和数据一致性

- [ ] HTML 报告实际导出落盘
  - 验收标准：能选择导出路径，生成 `.html` 文件，可在本机浏览器正常打开。
- [ ] PDF 报告实际导出落盘
  - 验收标准：能选择导出路径，生成 `.pdf` 文件，内容与报告预览一致。
- [ ] 结果页统计与数据库对账
  - 验收标准：统计卡片、事件列表、动态指标与 SQLite 中结果一致。
- [ ] `detections.json` 与 overlay 抽样对账
  - 验收标准：抽样帧的 bbox、类别名、confidence 与 UI overlay 一致。

### E. 错误路径

- [ ] 非法文件类型
  - 验收标准：桌面端明确拒绝，错误信息可读。
- [ ] 损坏视频文件
  - 验收标准：任务失败，错误原因清晰，不残留假完成状态。
- [ ] 缺失 `ffmpeg` / `ffprobe`
  - 验收标准：runtime 自检或任务失败信息直接指向外部依赖缺失。
- [ ] 缺失 `var-gpu-preprocessor` / `var-video-analyzer`
  - 验收标准：runtime 自检或 worker 错误信息直接指向缺失 sidecar。
- [ ] 磁盘空间不足
  - 验收标准：任务失败且提示明确，不产生半成品假结果。

## 4. 建议验证矩阵

| 编号 | 样本类型 | 关键配置 | 目标 |
| --- | --- | --- | --- |
| S1 | 合成无异常短视频 | 预处理关 | 验证最短主链和空 overlay |
| S2 | 合成无异常短视频 | 预处理开，轻度 | 验证 GPU 预处理分支 |
| S3 | 合成无异常短视频 | 预处理开，中度 | 验证默认基线 |
| S4 | 合成无异常短视频 | 预处理开，强度 | 验证高强度分支 |
| S5 | 真实单异常视频 | 熔池增强关 | 验证事件生成和 bbox overlay |
| S6 | 真实单异常视频 | 熔池增强开 | 验证增强分支 |
| S7 | 长视频 | 默认配置 | 验证进度、超时和稳定性 |
| S8 | 损坏视频 | 任意 | 验证失败路径 |

## 6. 完整功能验证通过的最低标准

1. `3. 必须补测` 全部通过。
2. 至少有一组真实业务视频样本成功生成异常事件，而不是只有合成空场景。
3. HTML / PDF 报告均完成实际导出落盘验证。
4. 删除、重新分析、多任务排队、重启恢复四类任务生命周期场景全部通过。
5. Windows runtime 导入、GPU/ONNX self-check 和 GPU 预处理真实视频烟测全部通过。
6. 不再出现“数据库已完成 / 已失败，但 UI 仍显示分析中”的状态不一致问题。
